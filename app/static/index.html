Bot Platform

Run and monitor browser bots

This panel only controls the bot. When you press Start, Selenium opens demo.arcaptcha.co inside the Chrome container, clicks the CAPTCHA, logs in, and saves the result here.

Launch

Available bots are loaded from the registry.

Browser mode

Headless: browser is invisible (you will not see the site on :7900).
Headful: open localhost:7900, click Connect, then Start run here — you should see demo.arcaptcha.co open automatically. Prefer Headful; ArCaptcha often blocks plain Headless automation.

Run history

Persisted across container restarts via the mounted SQLite volume.
